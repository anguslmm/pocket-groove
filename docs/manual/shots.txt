# Each block also checks a workflow the manual describes. `empty` + `boot` =
# a first power-on, which loads the ROM demo ACIDJAM (the harness's `demo` is
# the UX mockup project instead, so it is not used here).

# Power-on: the banner over GROOVE (first boot: ACIDJAM)
empty
boot
wait 200
shot m-boot

# Quick start: playing, BASS selected (the power-on selection)
empty
